# Leveraging Physics-Informed Machine Learning to Empower Genetic Algorithms for Mechanical Systems

MSc thesis · Universidade de São Paulo, 2023 · Advisor: Marcilio Alves

📄 **[Read the thesis](https://andre-thesis.com/)**

## Summary
Genetic algorithms for mechanical design optimization are bottlenecked by cost function
evaluation. Each candidate typically requires a full physics simulation. This
work replaces those evaluations with physics-informed ML surrogates.

Across the cases studied, the surrogate-based approach reached comparable or
better solutions than direct simulation, at a fraction of the runtime.
The results don't generalize trivially, but the approach looks promising.
